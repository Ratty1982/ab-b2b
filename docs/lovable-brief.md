# Automotive Trade Hub

Automotive Brands — B2B Commerce, Trade Portal & CRM Platform

Design a complete modern B2B automotive platform for Automotive Brands, using the domain automotivebrands.co.uk.

This is not a consumer ecommerce website and should not look like a generic Shopify/WooCommerce store.

Automotive Brands is an umbrella business supplying multiple automotive brands and product ranges to trade customers including motor factors, automotive retailers, workshops, garages, distributors and other B2B customers.

The existing Automotive Brands website is being completely replaced.

The new platform will eventually be custom-built and will contain:

Public corporate/brand website

B2B trade ecommerce portal

Trade customer account area

Sales representative portal

CRM

Internal administration area

For this phase, concentrate on producing an exceptional UX/UI design and working prototype.

Do not make backend technology decisions that unnecessarily lock the project into Lovable, Supabase or another platform. Backend functionality can be represented using realistic mock data where necessary.

DESIGN DIRECTION

The platform should feel like a substantial UK automotive aftermarket business.

The design should communicate:

Professional

Established

Automotive

Trade-focused

Premium

Modern

Reliable

Fast

Commercial

Avoid:

Generic SaaS styling

Excessive rounded cards

Huge amounts of empty space

Consumer lifestyle ecommerce styling

Cheap automotive styling

Overuse of gradients

Overly futuristic UI

Template-like layouts

Use strong typography, excellent information hierarchy, high-quality product imagery, clean tables and professional dashboards.

The public website should be visually impressive.

The B2B and CRM areas should prioritise speed, information density and usability.

Desktop is important, but the entire platform must be properly responsive.

The salesperson experience in particular must work exceptionally well on mobile and tablet.

IMPORTANT TECHNICAL BOUNDARY

This prototype is intended to become the design specification for a separately engineered production application.

Do NOT tightly couple the design to Supabase or Lovable-specific backend functionality.

Do NOT build Automotive Brands on WordPress or WooCommerce.

Do NOT integrate this project with AlphaOps.

Automotive Brands will be an independent system.

The eventual production architecture is expected to use technologies such as:

Next.js

TypeScript

NestJS

PostgreSQL

Prisma

Redis

However, this phase is primarily about creating the best possible UX/UI and validating the product.
